# Разработка системы двухфакторной аутентификации пользователей беспроводной сети на основе алгоритма TOTP

Проект демонстрирует реализацию двухфакторной аутентификации (TOTP) для Wi-Fi через PfSense и FreeRADIUS. Система позволяет:

- Настраивать права доступа и ограничения пользователей
- Ограничивать пропускную способность и время сессии
- Применять ограничения по IP и MAC-адресу
- Интегрировать с внешними базами данных для управления пользователями в крупных сетях
- Проверять одноразовые TOTP коды через PAM модуль

## Принцип работы

1. Клиент подключается к беспроводной сети и получает IP-адрес от DHCP сервера PfSense.
2. Первичная попытка выхода в интернет перенаправляется на Captive Portal с формой для логина, пароля и TOTP.
3. PfSense отправляет данные на внешний FreeRADIUS через протокол RADIUS (порт 1812).
4. FreeRADIUS проверяет данные и TOTP.
5. В случае успеха возвращается Access-Accept и клиент получает доступ в сеть.
6. Иначе возвращается Access-Reject, доступ блокируется.
